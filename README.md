# 📚 Bibliotec

### Interface Web para Gerenciamento de Biblioteca

O **Bibliotec** é um projeto acadêmico de desenvolvimento Front-End que simula a interface de um sistema de gerenciamento de biblioteca, contemplando diferentes perfis de utilização: **usuário e administrador**.

Desenvolvido com **HTML5, CSS3 e JavaScript**, o projeto tem como foco a estruturação de páginas, a estilização de componentes, a organização visual e a implementação de pequenas interações para proporcionar uma experiência de navegação intuitiva.

Atualmente, o Bibliotec representa um **protótipo navegável**, sem integração com Back-End ou banco de dados.

---

## 🎯 Objetivo do projeto

Aplicar os conhecimentos adquiridos em desenvolvimento Front-End por meio da construção de interfaces para um sistema de biblioteca, explorando:

- Estruturação semântica com HTML5;
- Estilização e organização de layouts com CSS3;
- Padronização e reutilização de componentes visuais;
- Navegação entre páginas;
- Pequenas interações com JavaScript;
- Boas práticas de UX/UI.

## 🖥️ Interfaces desenvolvidas

O projeto está organizado em diferentes áreas:

| Área | Descrição |
|---|---|
| Home | Interface inicial de apresentação e navegação |
| Login | Representação visual da tela de acesso |
| Visão do Usuário | Interfaces destinadas à experiência dos leitores |
| Visão Administrativa | Interfaces destinadas ao gerenciamento da biblioteca |

As páginas representam visualmente os fluxos e as funcionalidades planejadas para o sistema.

## 💻 Tecnologias utilizadas

| Tecnologia | Aplicação |
|---|---|

## ⚙️ Como executar o projeto

**1. Clone o repositório:**

```bash
git clone https://github.com/kessiamilena/Projeto-Bibliotec-Manha.git
```

**2. Acesse a pasta:**

```bash
cd Projeto-Bibliotec-Manha
```

**3. Abra o projeto no Visual Studio Code:**

```bash
code .
```

**4. Execute as páginas:**

Abra os arquivos `.html` diretamente no navegador ou utilize a extensão **Live Server** do Visual Studio Code.

Não é necessário instalar dependências ou configurar um servidor Back-End.

## ⚠️ Escopo atual e limitações

O Bibliotec encontra-se em uma etapa de desenvolvimento exclusivamente Front-End.

Nesta versão, **não estão implementados**:

- Autenticação real de usuários;
- Validação de credenciais;
- Controle de acesso e proteção de rotas;
- Integração com banco de dados;
- Persistência de informações;
- Operações reais de cadastro, edição ou exclusão de registros.

As telas de login, administração e gerenciamento são representações visuais. A navegação entre elas não depende de autenticação ou autorização.

O JavaScript é utilizado apenas para pequenas interações, animações e redirecionamentos entre páginas.

## 🚀 Possibilidades de evolução

Em futuras etapas, o projeto poderá receber:

- [ ] Desenvolvimento do Back-End (com arquitetura MVC);
- [ ] Integração com banco de dados;
- [ ] Autenticação e autorização de usuários;
- [ ] Implementação das regras de negócio;
- [ ] Operações de cadastro e gerenciamento de livros;
- [ ] Persistência de favoritos e dados dos usuários;
- [ ] Integração completa entre Front-End e Back-End.

Essas funcionalidades são possibilidades de evolução e não fazem parte do escopo atual.
